Quiz System — ใช้ไฟล์ CSV ของคุณ

ในโฟลเดอร์นี้มี:
- index.html: หน้าเว็บข้อสอบ
- style.css: รูปแบบหน้าเว็บ
- script.js: อ่าน CSV, แสดงข้อสอบ, ตรวจคะแนนและจับเวลา
- questions.csv: ไฟล์ข้อสอบต้นฉบับของคุณ (20 ข้อ)

วิธีเปิด:
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์นี้ด้วย VS Code
3. ติดตั้ง Extension "Live Server" ถ้ายังไม่มี
4. คลิกขวา index.html > Open with Live Server
5. กรอกชื่อ แล้วเริ่มทำข้อสอบ

หมายเหตุ:
- CSV ต้องอยู่ในโฟลเดอร์เดียวกับ index.html
- คอลัมน์ที่ระบบใช้อยู่คือ: ข้อ, คำถาม, ตัวเลือก ก, ตัวเลือก ข, ตัวเลือก ค, ตัวเลือก ง, เฉลย
- ระบบยังไม่บันทึกลง Google Sheets; ขั้นถัดไปสามารถเชื่อม Apps Script ได้
